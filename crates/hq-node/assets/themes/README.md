# Bundled theme sources

The six Gruvbox palettes are copied from Tinted Theming's MIT-licensed `schemes` repository,
branch `spec-0.11`, commit `fdca32a0d14ec80ad83a78a9ccb85592ca6cb9e1`:

https://github.com/tinted-theming/schemes/tree/fdca32a0d14ec80ad83a78a9ccb85592ca6cb9e1/base16

The YAML metadata retains the original scheme authors. HQ embeds only these selected palette files
and resolves them through the same Base16 importer used for user themes.
